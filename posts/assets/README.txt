This folder contains image assets for blog posts.

Structure:
  posts/assets/{post-slug}/banner.jpg   ← Banner image for post cards & post header
  posts/assets/{post-slug}/screenshot.jpg  ← Any inline images used in the post

Example:
  posts/assets/wwdc24-swift-student-challenge/banner.jpg
  posts/assets/building-sflix/banner.jpg

Recommended banner dimensions: 1200 × 630px (16:9 ratio)
Max file size: 500KB
